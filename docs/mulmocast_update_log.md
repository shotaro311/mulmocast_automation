# MulmoCast 機能詳細

このドキュメントでは、MulmoCastの主要なアップデートについて、機能の概要、使い方、活用イメージを詳しく解説します。

---

## 1. AIによるHTMLスライド生成 (`htmlPrompt`)
v0.0.22で導入された、AIを活用してHTML、CSS、JavaScriptを自動生成し、高度なスライドを作成する機能です。

### 概要
`htmlPrompt`を使用すると、自然言語で指示するだけで、単なる画像やテキストのスライドでは表現が難しかった、以下のような動的でリッチなコンテンツを生成できます。

*   **データ可視化**: 円グラフ、棒グラフ、折れ線グラフなど
*   **インフォグラフィック**: 図やイラストを多用した説明
*   **インタラクティブな要素**: アニメーションや簡単なデモ

### 使い方
MulmoScriptのシーン定義内で、`imagePrompt`の代わりに`htmlPrompt`を使用します。

**例：日本の人口推移を棒グラフで表示するスライド**
```json
{
  "script": [
    {
      "scene": "population_graph",
      "htmlPrompt": "2000年から2020年までの日本の総人口の推移を、5年ごとのデータで示す棒グラフを作成してください。Y軸は「人口（万人）」、X軸は「年」とします。",
      "speech": "こちらが、2000年から2020年までの日本の人口推移です。少子高齢化の影響が見て取れます。"
    }
  ]
}
```

### 活用イメージ
*   **ビジネスレポート**: 売上データや市場シェアをグラフ化し、説得力のあるプレゼンテーションを作成。
*   **教育コンテンツ**: 複雑な科学的プロセスや歴史的な出来事を、図解やアニメーションで分かりやすく解説。
*   **製品デモ**: ソフトウェアのUIの動きなどを、インタラクティブなスライドで紹介。

---

## 2. Replicate連携によるAI動画生成
v0.0.23で導入された、Replicate APIと連携してテキストから動画クリップを生成する機能です。

### 概要
テキストプロンプトを与えるだけで、AIがその内容に合った短い動画を生成します。これにより、プレゼンテーションのBロール映像や、ミュージックビデオのビジュアルなどを、素材を探すことなく作成できます。

### 使い方
1.  **.envファイルの設定**:
    お使いの環境の`.env`ファイルに、ReplicateのAPIキーを追加します。
    ```
    REPLICATE_API_KEY=your_replicate_api_key
    ```

2.  **MulmoScriptでの記述**:
    シーン定義内で`moviePrompt`を使用します。

    **例：近未来の都市の映像を生成**
    ```json
    {
      "scene": "future_city_video",
      "moviePrompt": "A futuristic city with flying cars and neon-lit skyscrapers, cinematic style, 4k resolution.",
      "speech": "AIが生成した未来の都市の映像をご覧ください。"
    }
    ```

### 活用イメージ
*   **ビデオポッドキャスト**: トピックに合わせたイメージ映像を背景に流す。
*   **ミュージックビデオ**: 歌詞の世界観を表現する抽象的なビジュアルや、具体的なシーンを生成。
*   **プレゼンテーション**: コンセプトを視覚的に補強するための、短い紹介映像やトランジションを挿入。

---

## 3. コンテンツ作成とインポートの効率化 (WebページからMulmoScript生成)
v0.0.23で導入された、Webページのコンテンツを自動でMulmoScriptに変換する機能です。

### 概要
指定したURLのWebページをAIが解析し、その内容（見出し、本文、画像など）を自動でシーンに分割してMulmoScriptを生成します。ニュース記事やブログ投稿の要約ビデオを素早く作成したい場合に非常に強力です。

### 使い方
コマンドラインで`mulmocast`を実行する際に、`--url`オプションで対象のWebページのURLを指定します。

```bash
# example.comの記事を読み込んで、script.jsonという名前で出力する
mulmocast --url https://example.com/article/some-news > script.json
```

### 活用イメージ
*   **ニュース解説動画**: 最新のニュース記事を数分で動画コンテンツ化。
*   **ブログのビデオ化**: 自身のブログ記事をビデオフォーマットで再利用し、YouTubeなどで発信。
*   **リサーチ内容の共有**: 参考にしたWebページの内容をスライド形式に変換し、チーム内で共有。

---

## 4. クリエイティブ機能の強化

### CSSベースのキャプションスタイリング (v0.0.24)
従来の固定的なプロパティ指定から、柔軟なCSS（カスケーディング・スタイル・シート）によるキャプションのスタイリングが可能になりました。

*   **概要**: `styles`ブロック内でCSSを直接記述することで、文字色、サイズ、フォントはもちろん、テキストシャドウ、グラデーション、アニメーションなど、表現の幅が大きく向上しました。
*   **使い方**:
    ```json
    "styles": {
      ".caption": "color: white; font-size: 48px; font-weight: bold; text-shadow: 2px 2px 8px rgba(0,0,0,0.8); animation: fadeIn 2s;"
    },
    "scenes": [
      {
        "scene": "intro",
        "imagePrompt": "A beautiful sunrise over a mountain range.",
        "caption": "新しい一日の始まり"
      }
    ]
    ```

### 新しいミュージックビデオテンプレート (v0.0.23)
ミュージックビデオ制作に特化した新しいテンプレートが追加され、より手軽にクリエイティブな映像を作成できるようになりました。

### アスペクトフィル対応 (v0.0.23)
画像や動画が画面サイズに満たない場合に、アスペクト比を維持したまま自動で拡大し、余白をなくす（フィルする）表示に対応しました。これにより、どんな素材でも全画面で見栄えの良い表示が可能です。

## 5. AIプロバイダーの拡充 (Anthropic Claude API)
v0.0.23より、OpenAIのGPTシリーズに加え、Anthropic社のClaude APIをサポートしました。

*   **概要**: `.env`ファイルに`ANTHROPIC_API_KEY`を設定することで、`htmlPrompt`やスクリプト生成などのAIタスクにClaudeモデルを使用できます。モデルの特性に応じて、異なるアウトプットを得られる可能性があります。
